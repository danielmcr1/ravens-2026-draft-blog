This blog was built as coursework for my DevOps module. It demonstrates a continuous integration and continuous deployment pipeline built entirely on GitHub Actions, deploying a Jekyll-based static site to GitHub Pages with linting, security scanning, dependency review, supply-chain attestation and infrastructure-as-code validation layered on top.

The chosen topic is the Baltimore Ravens' 2026 NFL Draft class.
